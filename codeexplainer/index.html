The request pipeline

One request, eleven stops. The order is the security model: each layer assumes the one before it can fail.

    Why prepend and append matter. SecurityHeaders is prepended, so it wraps the whole stack and can decorate redirects and error responses. The three session guards are appended after Laravel's session middleware, so they can read the session and the authenticated user.
