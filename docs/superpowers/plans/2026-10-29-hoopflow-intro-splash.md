# HoopFlow Intro Splash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a 6.5s, 1080×1920 animated HoopFlow intro splash as an H.264 MP4 built in Remotion.

**Architecture:** A Remotion project in `video/`. The bracket is the official PNG revealed through an animated SVG stroke mask; the ball is the same PNG split by a shared disk radius and moved as a unit. Timing lives in one `timeline.ts`; only `Splash.tsx` reads `useCurrentFrame()`.

**Tech Stack:** Remotion 4.0.539, React 19, TypeScript 5.9, Vitest, PowerShell + System.Drawing for asset prep and image diffing.

## Global Constraints

- Canvas: `1080 × 1920`, `fps: 30`, `durationInFrames: 195`. Composition id `HoopFlowSplash`.
- Colors: charcoal `#171D23`, orange `#F56103`, white `#FFFFFF`, motto `rgba(255,255,255,0.72)`, court line `rgba(255,255,255,0.05)`, glow `rgba(245,97,3,0.12)`.
- Motto copy: `Let the games run themselves.` Wordmark: `HoopFlow` (8 letters, `Hoop` white, `Flow` orange).
- Icon source: `../logo/hoopflow icon without background.png`, 302×292, ball center `(149, 60)`, stroke 12 units.
- No component may hardcode a frame number. All frames come from `src/timeline.ts`.
- TypeScript `strict: true`. No `any`, no non-null assertions.
- Every commit runs from the repo root `C:\Users\JewardMahinay\Downloads\hoopflow development`.
- Remotion audio: delay with `<Sequence from={…}>`; trim with `trimBefore` + `durationInFrames` (verified against 4.0.539 docs).

### Task 3: Split the icon into bracket and ball assets

**Files:**

- [ ] **Step 1: Write `video/tools/prepare-assets.ps1`**

```powershell
Add-Type -AssemblyName System.Drawing
$ErrorActionPreference = 'Stop'

$sourcePath = Join-Path (Resolve-Path '..\logo') 'hoopflow icon without background.png'
$outDir = Join-Path (Get-Location) 'public\brand'
$metricsDir = Join-Path (Get-Location) 'src\geometry'
New-Item -ItemType Directory -Force $outDir | Out-Null
New-Item -ItemType Directory -Force $metricsDir | Out-Null

$src = [System.Drawing.Bitmap]::FromFile($sourcePath)
$width = $src.Width
$height = $src.Height
$cx = 149.0
$cy = 60.0
$radius = 49.5

$bracket = New-Object System.Drawing.Bitmap $width, $height, ([System.Drawing.Imaging.PixelFormat]::Format32bppArgb)
$ball = New-Object System.Drawing.Bitmap $width, $height, ([System.Drawing.Imaging.PixelFormat]::Format32bppArgb)

$mismatched = 0
for ($y = 0; $y -lt $height; $y++) {
  for ($x = 0; $x -lt $width; $x++) {
    $colour = $src.GetPixel($x, $y)
    $dx = ($x + 0.5) - $cx
    $dy = ($y + 0.5) - $cy
    $inside = ($dx * $dx + $dy * $dy) -le ($radius * $radius)
    if ($inside) {
      $ball.SetPixel($x, $y, $colour)
      $bracket.SetPixel($x, $y, [System.Drawing.Color]::FromArgb(0, 0, 0, 0))
    } else {
      $bracket.SetPixel($x, $y, $colour)
      $ball.SetPixel($x, $y, [System.Drawing.Color]::FromArgb(0, 0, 0, 0))
    }
  }
}

for ($y = 0; $y -lt $height; $y++) {
  for ($x = 0; $x -lt $width; $x++) {
    $sourceAlpha = $src.GetPixel($x, $y).A
    $splitAlpha = [Math]::Max($bracket.GetPixel($x, $y).A, $ball.GetPixel($x, $y).A)
    if ([Math]::Abs($sourceAlpha - $splitAlpha) -gt 1) { $mismatched++ }
  }
}

$bracket.Save((Join-Path $outDir 'bracket.png'), [System.Drawing.Imaging.ImageFormat]::Png)
$ball.Save((Join-Path $outDir 'ball.png'), [System.Drawing.Imaging.ImageFormat]::Png)

@{
  width = $width
  height = $height
  strokeWidth = 12
  ball = @{ cx = $cx; cy = $cy; radius = $radius }
} | ConvertTo-Json -Depth 5 | Set-Content -Encoding utf8 (Join-Path $metricsDir 'icon-metrics.json')

Write-Output "source=${width}x${height} ball=($cx,$cy) r=$radius alphaMismatches=$mismatched"
$src.Dispose(); $bracket.Dispose(); $ball.Dispose()
```

- [ ] **Step 2: Write `video/src/components/BracketMark.tsx`**

Remotion's `<Img>` renders a native `<img>`, which is invalid inside `<svg>`. So the reveal mask is a generated SVG data URL applied as a **CSS mask** on a `<div>` wrapping `<Img>` — that keeps `<Img>`, so Remotion still guarantees load-before-capture. CSS masks composite by alpha, so the backing rect is omitted: only stroked paths are opaque, everything else stays transparent (hidden).

```tsx
import type { CSSProperties } from "react";
import { Img, staticFile } from "remotion";
import maskData from "../geometry/maskPaths.json";
import metrics from "../geometry/icon-metrics.json";
import { LAYOUT } from "../theme";
import type { RevealGroupName } from "../timeline";

const VIEW_W = 302;
const VIEW_H = 292;
const MASK_STROKE = maskData.strokeWidth;

export type BracketMarkProps = {
  reveal: Record<RevealGroupName, number>;
  drop: number;
  squash: number;
  ballOpacity: number;
  width?: number;
};

const polylinesFor = (name: RevealGroupName): number[][][] =>
  (maskData.groups as Record<string, number[][][]>)[name] ?? [];

const toPath = (points: number[][]): string =>
  points.map(([x, y], index) => `${index === 0 ? "M" : "L"} ${x} ${y}`).join(" ");

const buildMask = (reveal: Record<RevealGroupName, number>): string => {
  const paths = (Object.keys(reveal) as RevealGroupName[])
    .flatMap((name) =>
      polylinesFor(name).map(
        (points) =>
          `<path d="${toPath(points)}" fill="none" stroke="white" stroke-width="${MASK_STROKE}" stroke-linecap="round" stroke-linejoin="round" pathLength="1" stroke-dasharray="1" stroke-dashoffset="${1 - reveal[name]}"/>`,
      ),
    )
    .join("");
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 ${VIEW_W} ${VIEW_H}" preserveAspectRatio="none">${paths}</svg>`;
  return `url("data:image/svg+xml;charset=utf-8,${encodeURIComponent(svg)}")`;
};

export const BracketMark: React.FC<BracketMarkProps> = ({
  reveal,
  drop,
  squash,
  ballOpacity,
  width = LAYOUT.iconWidth,
}) => {
  const height = (width * VIEW_H) / VIEW_W;
  const unit = width / VIEW_W;
  const { cx, cy } = metrics.ball;
  const scaleX = 1 + 0.1 * squash;
  const scaleY = 1 - 0.14 * squash;
  const maskImage = buildMask(reveal);

  const maskStyle: CSSProperties = {
    position: "absolute",
    inset: 0,
    maskImage,
    WebkitMaskImage: maskImage,
    maskSize: "100% 100%",
    WebkitMaskSize: "100% 100%",
    maskRepeat: "no-repeat",
    WebkitMaskRepeat: "no-repeat",
  };

  return (
    <div style={{ position: "relative", width, height }}>
      <div style={maskStyle}>
        <Img
          src={staticFile("brand/bracket.png")}
          style={{ width: "100%", height: "100%", display: "block" }}
        />
      </div>
      <div
        style={{
          position: "absolute",
          inset: 0,
          opacity: ballOpacity,
          transform: `translateY(${drop * unit}px) scale(${scaleX}, ${scaleY})`,
          transformOrigin: `${(cx / VIEW_W) * 100}% ${(cy / VIEW_H) * 100}%`,
        }}
      >
        <Img
          src={staticFile("brand/ball.png")}
          style={{ width: "100%", height: "100%", display: "block" }}
        />
      </div>
    </div>
  );
};
```

```powershell
Add-Type -AssemblyName System.Drawing
$ErrorActionPreference = 'Stop'

$sourcePath = Join-Path (Resolve-Path '..\logo') 'hoopflow icon without background.png'
$maskPath = Join-Path (Get-Location) 'src\geometry\maskPaths.json'
$mask = Get-Content $maskPath -Raw | ConvertFrom-Json

$segments = New-Object System.Collections.ArrayList
foreach ($group in $mask.groups.PSObject.Properties) {
  foreach ($line in $group.Value) {
    for ($i = 0; $i -lt $line.Count - 1; $i++) {
      [void]$segments.Add(@($line[$i][0], $line[$i][1], $line[$i + 1][0], $line[$i + 1][1]))
    }
  }
}

function Get-InkSet([string]$path) {
  $bmp = [System.Drawing.Bitmap]::FromFile((Resolve-Path $path))
  $set = New-Object 'System.Collections.Generic.HashSet[string]'
  for ($y = 0; $y -lt $bmp.Height; $y++) {
    for ($x = 0; $x -lt $bmp.Width; $x++) {
      if ($bmp.GetPixel($x, $y).A -gt 100) { [void]$set.Add("$x,$y") }
    }
  }
  $bmp.Dispose()
  return ,$set
}

function Get-PointDistance([double]$px, [double]$py, $seg) {
  $x1 = $seg[0]; $y1 = $seg[1]; $x2 = $seg[2]; $y2 = $seg[3]
  $dx = $x2 - $x1; $dy = $y2 - $y1
  $lengthSquared = $dx * $dx + $dy * $dy

  return [Math]::Sqrt([Math]::Pow($px - ($x1 + $t * $dx), 2) + [Math]::Pow($py - ($y1 + $t * $dy), 2))
}

  }

}
```

```ts
const LIFT_START = 57;
const LIFT_PEAK = 66;
const IMPACT = 74;
const SQUASH_END = 84;
const LIFT_HEIGHT = -16;

const easeOut = (t: number): number => 1 - (1 - t) * (1 - t);
const easeIn = (t: number): number => t * t;
const lerp = (a: number, b: number, t: number): number => a + (b - a) * t;
const clamp = (t: number): number => Math.min(1, Math.max(0, t));

export const ballDrop = (frame: number): number => {
  if (frame <= LIFT_START) return 0;
  if (frame <= LIFT_PEAK) {
    return lerp(0, LIFT_HEIGHT, easeOut((frame - LIFT_START) / (LIFT_PEAK - LIFT_START)));
  }
  if (frame <= IMPACT) {
    return lerp(LIFT_HEIGHT, 0, easeIn((frame - LIFT_PEAK) / (IMPACT - LIFT_PEAK)));
  }
  return 0;
};

export const ballSquash = (frame: number): number => {
  if (frame < IMPACT || frame > SQUASH_END) return 0;
  const t = clamp((frame - IMPACT) / (SQUASH_END - IMPACT));
  return Math.sin(Math.PI * t);
};
```

```ts
export type WavInput = {
  sampleRate: number;
  samples: Float32Array;
};

const HEADER_BYTES = 44;
const BYTES_PER_SAMPLE = 2;

export const encodeWav = ({ sampleRate, samples }: WavInput): Uint8Array => {
  const dataSize = samples.length * BYTES_PER_SAMPLE;
  const buffer = new ArrayBuffer(HEADER_BYTES + dataSize);
  const view = new DataView(buffer);

  const writeAscii = (offset: number, text: string): void => {
    for (let index = 0; index < text.length; index++) {
      view.setUint8(offset + index, text.charCodeAt(index));
    }
  };

  writeAscii(0, "RIFF");
  view.setUint32(4, 36 + dataSize, true);
  writeAscii(8, "WAVE");
  writeAscii(12, "fmt ");
  view.setUint32(16, 16, true);
  view.setUint16(20, 1, true);
  view.setUint16(22, 1, true);
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, sampleRate * BYTES_PER_SAMPLE, true);
  view.setUint16(32, BYTES_PER_SAMPLE, true);
  view.setUint16(34, 16, true);
  writeAscii(36, "data");
  view.setUint32(40, dataSize, true);

  for (let index = 0; index < samples.length; index++) {
    const clamped = Math.max(-1, Math.min(1, samples[index]));
    const value = clamped < 0 ? clamped * 0x8000 : clamped * 0x7fff;
    view.setInt16(HEADER_BYTES + index * BYTES_PER_SAMPLE, value, true);
  }

  return new Uint8Array(buffer);
};
```

```js
    const centre = 400 + 2000 * Math.pow(progress, 0.7);
    const cutoff = Math.min(0.99, (2 * Math.PI * centre) / SAMPLE_RATE);
    const noise = random() * 2 - 1;

    lowState += cutoff * (noise - lowState);
    highState += cutoff * (lowState - highState);
    const band = lowState - highState;

    const attack = Math.min(1, i / (SAMPLE_RATE * 0.15));
    const decay = Math.exp(-3.2 * progress);
    samples[i] = band * attack * decay;
  }

  return peakNormalise(samples, -14);
};

const swish = () => {
  const duration = 0.5;
  const total = Math.floor(SAMPLE_RATE * duration);
  const samples = new Float32Array(total);
  const random = mulberry32(0xbadc0de);
  let highState = 0;

  for (let i = 0; i < total; i++) {
    const time = i / SAMPLE_RATE;
    const noise = random() * 2 - 1;
    highState += 0.35 * (noise - highState);
    const hiss = noise - highState;
    const hissEnvelope = Math.exp(-18 * time);
    const thump = Math.sin(2 * Math.PI * 90 * time) * Math.exp(-16.7 * time);
    samples[i] = hiss * hissEnvelope * 0.8 + thump * 0.6;
  }

  return peakNormalise(samples, -10);
};

mkdirSync(OUT_DIR, { recursive: true });
const files = [
  ["whoosh.wav", whoosh()],
  ["swish.wav", swish()],
];

for (const [name, samples] of files) {
  const bytes = encodeWav({ sampleRate: SAMPLE_RATE, samples });
  writeFileSync(join(OUT_DIR, name), bytes);
  console.log(`${name}: ${(bytes.byteLength / 1024).toFixed(1)} KB, ${(samples.length / SAMPLE_RATE).toFixed(2)}s`);
}
```
